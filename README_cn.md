## 1. 项目概述

本项目旨在对斯坦福大学的 Generative Agents 项目进行深度中国化改造，创造一个具有真实中国文化背景、情感记忆和人格特质的 AI 代理（Agent）模拟环境——“青石镇”。

我们集成了 **memos-mind 情感记忆系统**，为每个代理赋予了“灵魂”，使其能够体验和记忆情感。同时，我们开发了 **“上帝之眼”观察系统**，用于监控和分析代理的心理状态、社会关系和行为演变。

本地化的核心目标是超越简单的文本翻译，通过对角色背景、社会关系、场景环境和互动模式的深度重塑，构建一个文化上可信的中国虚拟社会。

## 2. 本地化设计理念：混合方案

我们采用了“混合方案”（Hybrid Approach）进行本地化，其核心原则是：

- **保留核心，重塑表现**：保留原始项目的核心计算框架（如 Big Five 人格模型、Schwartz 价值观）和地图物理结构（100x140 坐标系），以确保计算兼容性和前端显示一致性。
- **深度重塑角色**：完全重新设计 25 个代理的角色，赋予他们地道的中国姓名、家庭背景、职业、人际关系和行为动机。
- **文化场景映射**：将原始的西方场景（如咖啡馆、酒吧）映射为具有中国文化特色的对应场景（如茶馆、小酒馆），同时保留其在地图上的坐标和功能定位。
- **融入文化维度**：在代理的行为和对话逻辑中，融入了“面子”、“人情”、“集体主义”等中国特有的文化维度。

## 3. 角色设计：25 位青石镇居民

我们为青石镇设计了 25 位性格各异、背景丰富的居民。每个角色都拥有独特的“先天”性格（innate）、“后天”认知（learned）、生活方式和日常规划。此外，我们还引入了三个关键的文化特质：

- **面子 (Face Consciousness)**: 角色在社交互动中对自身声誉和他人看法的敏感度。
- **人情 (Renqing)**: 基于互惠原则的社交义务和人情债。
- **集体主义 (Collectivism)**: 角色在多大程度上优先考虑集体（家庭、社区）的利益而非个人利益。

## 5. 技术实现与验证

- **配置文件生成**：通过脚本批量生成了 25 个角色的 JSON 配置文件，并存储于 `generative_agents/frontend/static/assets/qingshi_town/agents/`。
- **场景数据更新**：修改了 `maze.json` 文件，将所有场景地址替换为中文名称，并更新 `world` 名称为“青石镇”。
- **兼容性测试**：编写并运行了 `test_chinese_config.py` 脚本，对 `maze.json`、角色配置、坐标分布和 `sprite.json` 进行了全面验证，所有测试均已通过。

## 6. 如何运行

1. **切换分支**: 确保您在 `memos-mind-integration` 分支。
2. **启动环境**: 按照主项目的说明启动后端和前端服务。
3. **选择世界**: 在前端界面中，选择“青石镇”作为模拟世界。
4. **观察**: 系统将加载所有中国化配置，您可以开始观察青石镇居民的生活。
